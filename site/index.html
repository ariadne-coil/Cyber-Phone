Network posture

One client, multiple trust models.

Cyber Phone is not locked into a single network story. Core phone and local data paths can stay on-device. Mesh features operate as a separate transport layer. Wallet features can reach external Bitcoin and federation infrastructure when the user enables them.

That separation matters. It keeps permissions, transport behavior, and data exposure tied to the feature the user actually wants, instead of forcing a monolithic cloud dependency.
